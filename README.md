# Annoying Stuff Remover

![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21.4%2C%201.21.1%2C%201.20.1-blue) ![Modrinth](https://img.shields.io/badge/Modrinth-Available-brightgreen) ![License](https://img.shields.io/badge/License-MPL%202.0-blue)

A simple Minecraft Java Edition mod for 1.21.4, 1.21.1, and 1.20.1 on Forge and NeoForge that removes some of the more annoying features of the game.

## Features

- **Disable Accessibility Onboarding**: Prevents the accessibility onboarding screen "press key for narrator" from appearing
- **Disable Multiplayer Warning**: Removes the multiplayer warning splash screen
- **Skip Tutorial**: Skips the tutorial when starting a new world
- **Disable Recipe Book**: Disables the recipe book in the inventory and crafting tables
- **Skip Experimental Features Warning**: Skips the warning screen when enabling experimental features in a world
